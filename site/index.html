One app for all your studio lights.

Gaffer controls lights from different brands in one place. Set the brightness and the colour temperature from your Mac or from your phone.

Download Gaffer See the code on GitHub

Gaffer is still being built. Today it finds nearby lights and shows them by brand. Light control is coming.

What Gaffer is

Most light brands ship their own app. If you use more than one brand, you juggle more than one app. Gaffer replaces them with one.

It lives in your Mac menu bar, opens into a full window, and works on any phone in a browser.

Lights it works with

Godox

Bluetooth mesh lights. 186 models, including the Litemons LA150Bi.

Zhiyun

ZY Vega lights, including the MOLUS G200.

Yongnuo

Bluetooth lights, including the YN150Li.

What it does

Menu bar

A small icon shows the current look. Click it for quick control.

Mac window

A full window with a big colour temperature readout and sliders.

Phone browser

Scan a QR code on your Mac, then enter a PIN. No app to install on your phone.

Looks

Save the settings for many lights as one look, such as "Talking head". Each look has its own fade time.

Lighting desk

Switch to one fader per light. Select several and move them together.

Schedules

Switch to a look at a set time on set days, such as "All off at 2:00 AM".

Cues

Step through a list of looks with a button or a keyboard shortcut.

Install

  1. Download the latest zip from the releases page.
  2. Unzip it.
  3. Open Gaffer.app.

Gaffer is unsigned. The first time you open it, macOS asks you to confirm. The first time it scans, macOS also asks for Bluetooth. Click Allow.

The README will have the step-by-step guide with screenshots.

Licence and credits

Gaffer is free software under the MIT licence.

It builds on these MIT-licensed projects:

  • lumen-studio (MIT): Godox driver, model table, effects, scenes, schedules and cues.
  • godox-ul60bi-bt (MIT): the Godox protocol that lumen-studio builds on.
  • ha-godox-mesh (MIT): Godox mesh support for many models, also behind lumen-studio.
  • HA-Zhiyun-Light (MIT): Zhiyun protocol and light names.
  • zhiyun-light-control (MIT): Zhiyun protocol.
  • yongnuo-light-control (MIT): Yongnuo protocol and naming.
